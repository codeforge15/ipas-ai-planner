# iPAS AI 應用規劃師（初級）備考筆記

個人備考用的整理筆記與線上練習題庫，以 GitHub Pages 發佈方便手機查閱。

**網站**：https://codeforge15.github.io/ipas-ai-planner/

## 內容

| 檔案 | 說明 |
|---|---|
| `筆記_科目一_人工智慧基礎概論.md` | AI 概念、資料處理與統計、機器學習、鑑別式與生成式 AI |
| `筆記_科目二_生成式AI應用與規劃.md` | No Code / Low Code、生成式 AI 應用與工具、導入評估規劃與風險管理 |
| `題庫.html` | 單檔前端題庫，369 題，支援篩選、隨機出題、錯題本、成績分析。零安裝、可離線使用 |

## 題庫

- 69 題出自兩份學習指引所附模擬考題，**解析為自行改寫整理**，非官方原文
- 300 題出自六份官方公告試題（114-4、115-1、115-2，每份 50 題）。官方僅公布答案未附解析，故題庫中這些題目只顯示正解
- 主題分類為關鍵字自動歸類，僅供篩選參考
- 作答紀錄與錯題本存在瀏覽器 localStorage，不會上傳任何資料
